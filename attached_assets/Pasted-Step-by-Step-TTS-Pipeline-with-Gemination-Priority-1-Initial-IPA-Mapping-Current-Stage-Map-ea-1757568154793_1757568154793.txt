Step-by-Step TTS Pipeline with Gemination Priority

1. Initial IPA Mapping (Current Stage)

· Map each Arabic grapheme to its base IPA/X-SAMPA value (e.g., ب → /b/).
· Output: A flat list of phonemes with positional tags (word-initial, medial, final).

2. Gemination Processing (Shadda ّ)

· Rule: A consonant with shadda is geminated (doubled in duration).
· Implementation:
  · Detect shadda (ّ) in the input text.
  · Modify the preceding consonant’s IPA to mark gemination (e.g., /b/ → /b:/).
  · Delete the shadda from further processing (it’s now represented by the gemination symbol :).

3. Positional Allophonic Rules

· Apply dialect-specific changes based on position and neighboring phonemes:
  · Examples:
    · Word-Final Devoicing: /d/ → /t/ in some dialects.
    · Emphatic Spread: A consonant near emphatics (e.g., ص, ط) may become pharyngealized.
    · Intervocalic Lenition: /k/ → /g/ between vowels in Gulf Arabic.

4. Coarticulation & Assimilation

· Preceding/Following Context Matters:
  · Velarization: /s/ → /sˁ/ if followed by an emphatic consonant.
  · Nasal Assimilation: /n/ → /m/ before /b/ (e.g., "من بيروت" → /m biːruːt/).
· Implementation:
  · Iterate through the phoneme list and apply rules based on adjacent phonemes.

5. Prosody and Suprasegmentals

· Syllabification: Group phonemes into syllables (critical for stress and timing).
· Stress Patterns: Assign primary stress based on dialect (e.g., MSA: penultimate syllable).
· Pauses/Intonation: Mark phrase boundaries (e.g., # for pauses, ↑ for question rise).

6. Final Output for Synthesis

· Format the processed phonemes into a synthesis-friendly notation (e.g., SAMPA or SSML).
· Example:
  ```
  /bː/ /a/ /sˁ/ /m/ /#/   (for "باصّ من" with gemination and emphatic spread)
  ```
