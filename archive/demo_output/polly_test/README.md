# Polly POC Test Output Directory

This directory contains audio files generated by the Amazon Polly integration proof-of-concept test.

## Purpose

Compare audio quality between:
- **Amazon Polly** (neural TTS engine)
- **eSpeak NG** (baseline TTS engine)

## File Naming Convention

### Polly Audio Files
```
test_polly_<number>_<voice>_<engine>.mp3
```

**Example:** `test_polly_001_zeina_standard.mp3`

- `<number>`: Test case number (001-005), zero-padded
- `<voice>`: Polly voice ID (e.g., `zeina` for MSA, `hala` for Gulf)
- `<engine>`: Polly engine type (`neural` or `standard`)
- Format: MP3

### eSpeak Audio Files
```
test_polly_<number>_espeak.wav
```

**Example:** `test_polly_001_espeak.wav`

- `<number>`: Test case number (001-005), zero-padded
- Format: WAV

## Test Sentences

The POC uses 5 test sentences covering diverse phonetic patterns:

| # | Arabic Text | Translation | Phonetic Pattern |
|---|-------------|-------------|------------------|

| 002 | المدرسة الجديدة | The new school | Consonant clusters |
| 003 | كتابٌ جديدٌ | A new book | Tanween (nunation) |
| 004 | ذهبتُ إلى السوق لشراء بعض الخضروات والفواكه | I went to the market to buy some vegetables and fruits | Long sentence (10-15 words) |
| 005 | القواعد الإملائية والنحوية | Spelling and grammatical rules | Challenging phonemes |

## How to Generate Audio Files

Run the test script from the project root:

```bash
python scripts/test_polly_integration.py
```

**Prerequisites:**
- AWS credentials configured (see `docs/polly/AWS_SETUP_GUIDE.md`)
- boto3 installed: `pip install boto3>=1.28.0`
- eSpeak NG installed (for comparison audio)

## Evaluation Criteria

When listening to the audio files, assess:

### Audio Quality (SM-006)
- [ ] Polly audio quality is significantly better than eSpeak
- [ ] Natural-sounding speech vs. robotic speech
- [ ] Clear pronunciation and intonation

### Pronunciation Accuracy (SM-007, SM-008)
- [ ] Correct pronunciation of Arabic phonemes
- [ ] Accurate diacritics rendering
- [ ] Proper handling of sun/moon letters
- [ ] Native speaker validation ≥90% accuracy

### Comparison Checklist
For each pair of files (Polly vs eSpeak):
1. Play Polly audio first
2. Play eSpeak audio second
3. Note differences in:
   - Naturalness
   - Pronunciation accuracy
   - Clarity
   - Prosody/intonation

## Troubleshooting

**No Polly files generated?**
- Check AWS credentials: `aws configure list`
- Verify boto3 installed: `python3 -c "import boto3; print(boto3.__version__)"`
- Review error messages in test script output

**No eSpeak files generated?**
- Verify eSpeak installed: `espeak-ng --version`
- Install if missing: `sudo apt install espeak-ng` (Ubuntu/Debian)

**Audio files won't play?**
- Polly MP3: Use any media player (VLC, mpv, browser)
- eSpeak WAV: Use media player or command: `aplay test_polly_001_espeak.wav`
