### Potential Challenges & Solutions

**Challenge 1: Syllabification Edge Cases**
- **Issue:** Arabic syllable boundaries can be ambiguous
- **Solution:** Start with simple onset-nucleus-coda rules, refine iteratively
- **Timebox:** 2 days max - simplify if too complex

**Challenge 2: Emphatic Spread Scope**
- **Issue:** Pharyngealization can spread across syllable boundaries
- **Solution:** Start with single-syllable spread, defer multi-syllable to Phase 2
- **Reference:** May need linguistic research

**Challenge 3: eSpeak IPA Format**
- **Issue:** eSpeak uses X-SAMPA, not standard IPA
- **Solution:** Create conversion layer in `src/integrations/espeak.py`
- **Reference:** https://en.wikipedia.org/wiki/X-SAMPA

**Challenge 4: mishkal Diacritization Errors**
- **Issue:** mishkal is ~84% accurate
- **Solution:** Add error handling, allow manual override in UI
- **Future:** Consider Farasa or Shakkala for better accuracy (Phase 2)

**Challenge 5: Audio Quality Validation**
- **Issue:** No automated MOS score calculation yet
- **Solution:** Manual listening + native speaker feedback
- **Future:** Implement PESQ/STOI metrics (Phase 2)
